# ContentState

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `color` | Yes | string | hex string representing color of state |
| `id` | Yes | integer | identifier of content state. If 0, 1, or 2, this is a default space state |
| `name` | Yes | string | name of content state. |
