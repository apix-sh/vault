# SpaceSettingsUpdate

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `routeOverrideEnabled` | No | boolean | Defines whether an override for the space home should be used. This is<br/>used in conjunction with a space theme provided by an app. For<br/>example, if this property is set to true, a theme can display a page<br/>other than the space homepage when users visit the root URL for a<br/>space. This property allows apps to provide content-only theming<br/>without overriding the space home. |
