# SpaceUpdate


The properties of a space that can be updated.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | No | [SpaceDescriptionCreate](SpaceDescriptionCreate.md) |  |
| `homepage` | No | object | The updated homepage for this space |
| `name` | No | string | The updated name of the space. |
| `status` | No | string | The updated status for this space. |
| `type` | No | string | The updated type for this space. |
