# ApplicationProperty


Details of an application property.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `allowedValues` | No | array<string> | The allowed values, if applicable. |
| `defaultValue` | No | string | The default value of the application property. |
| `desc` | No | string | The description of the application property. |
| `example` | No | string |  |
| `id` | No | string | The ID of the application property. The ID and key are the same. |
| `key` | No | string | The key of the application property. The ID and key are the same. |
| `name` | No | string | The name of the application property. |
| `type` | No | string | The data type of the application property. |
| `value` | No | string | The new value. |
