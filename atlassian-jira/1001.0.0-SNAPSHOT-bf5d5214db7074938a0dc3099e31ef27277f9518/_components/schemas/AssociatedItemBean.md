# AssociatedItemBean


Details of an item associated with the changed record.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `id` | No | string | The ID of the associated record. |
| `name` | No | string | The name of the associated record. |
| `parentId` | No | string | The ID of the associated parent record. |
| `parentName` | No | string | The name of the associated parent record. |
| `typeName` | No | string | The type of the associated record. |
