# AttachmentArchiveItemReadable


Metadata for an item in an attachment archive.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `index` | No | integer | The position of the item within the archive. |
| `label` | No | string | The label for the archive item. |
| `mediaType` | No | string | The MIME type of the archive item. |
| `path` | No | string | The path of the archive item. |
| `size` | No | string | The size of the archive item. |
