# AutoCompleteSuggestion


A field auto-complete suggestion.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `displayName` | No | string | The display name of a suggested item. If `fieldValue` or `predicateValue` are provided, the matching text is highlighted with the HTML bold tag. |
| `value` | No | string | The value of a suggested item. |
