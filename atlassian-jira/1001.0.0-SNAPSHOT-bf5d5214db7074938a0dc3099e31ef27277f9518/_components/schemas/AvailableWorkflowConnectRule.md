# AvailableWorkflowConnectRule


The Connect provided ecosystem rules available.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `addonKey` | No | string | The add-on providing the rule. |
| `createUrl` | No | string | The URL creation path segment defined in the Connect module. |
| `description` | No | string | The rule description. |
| `editUrl` | No | string | The URL edit path segment defined in the Connect module. |
| `moduleKey` | No | string | The module providing the rule. |
| `name` | No | string | The rule name. |
| `ruleKey` | No | string | The rule key. |
| `ruleType` | No | string | The rule type. Allowed values: Condition, Validator, Function, Screen |
| `viewUrl` | No | string | The URL view path segment defined in the Connect module. |
