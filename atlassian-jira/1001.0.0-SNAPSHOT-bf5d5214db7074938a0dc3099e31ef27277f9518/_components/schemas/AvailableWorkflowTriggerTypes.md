# AvailableWorkflowTriggerTypes


The list of available trigger types.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | No | string | The description of the trigger rule. |
| `name` | No | string | The name of the trigger rule. |
| `type` | No | string | The type identifier of trigger rule. |
