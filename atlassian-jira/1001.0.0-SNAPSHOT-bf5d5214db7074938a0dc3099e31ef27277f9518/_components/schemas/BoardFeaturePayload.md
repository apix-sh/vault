# BoardFeaturePayload


The payload for setting a board feature

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `featureKey` | No | string | The key of the feature Allowed values: ESTIMATION, SPRINTS |
| `state` | No | boolean | Whether the feature should be turned on or off |
