# BulkContextualConfiguration


Details of the contextual configuration for a custom field.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `configuration` | No | any | The field configuration. |
| `customFieldId` | Yes | string | The ID of the custom field. |
| `fieldContextId` | Yes | string | The ID of the field context the configuration is associated with. |
| `id` | Yes | string | The ID of the configuration. |
| `schema` | No | any | The field value schema. |
