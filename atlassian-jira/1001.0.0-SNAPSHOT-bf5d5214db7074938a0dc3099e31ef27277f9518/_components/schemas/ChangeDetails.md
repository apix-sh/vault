# ChangeDetails


A change item.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `field` | No | string | The name of the field changed. |
| `fieldId` | No | string | The ID of the field changed. |
| `fieldtype` | No | string | The type of the field changed. |
| `from` | No | string | The details of the original value. |
| `fromString` | No | string | The details of the original value as a string. |
| `to` | No | string | The details of the new value. |
| `toString` | No | string | The details of the new value as a string. |
