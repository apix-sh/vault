# ChangedValueBean


Details of names changed in the record event.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `changedFrom` | No | string | The value of the field before the change. |
| `changedTo` | No | string | The value of the field after the change. |
| `fieldName` | No | string | The name of the field changed. |
