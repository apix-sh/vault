# CustomFieldContext


The details of a custom field context.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | Yes | string | The description of the context. |
| `id` | Yes | string | The ID of the context. |
| `isAnyIssueType` | Yes | boolean | Whether the context apply to all issue types. |
| `isGlobalContext` | Yes | boolean | Whether the context is global. |
| `name` | Yes | string | The name of the context. |
