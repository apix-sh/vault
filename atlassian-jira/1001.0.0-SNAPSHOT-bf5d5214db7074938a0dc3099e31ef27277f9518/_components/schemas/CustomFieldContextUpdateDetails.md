# CustomFieldContextUpdateDetails


Details of a custom field context.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | No | string | The description of the custom field context. The maximum length is 255 characters. |
| `name` | No | string | The name of the custom field context. The name must be unique. The maximum length is 255 characters. |
