# CustomFieldReplacement


Details about the replacement for a deleted version.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `customFieldId` | No | integer | The ID of the custom field in which to replace the version number. |
| `moveTo` | No | integer | The version number to use as a replacement for the deleted version. |
