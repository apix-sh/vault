# CustomTemplateOptions

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `enableScreenDelegatedAdminSupport` | No | boolean | Enable screen delegated admin support for the template. This means screen and associated schemes will be copied rather than referenced. |
| `enableWorkflowDelegatedAdminSupport` | No | boolean | Enable workflow delegated admin support for the template. This means workflows and workflow schemes will be copied rather than referenced. |
