# DateRangeFilterRequest


List issues archived within a specified date range.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `dateAfter` | Yes | string | List issues archived after a specified date, passed in the YYYY-MM-DD format. |
| `dateBefore` | Yes | string | List issues archived before a specified date provided in the YYYY-MM-DD format. |
