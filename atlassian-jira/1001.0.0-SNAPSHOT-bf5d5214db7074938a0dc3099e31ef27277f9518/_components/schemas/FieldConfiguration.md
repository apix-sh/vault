# FieldConfiguration


Details of a field configuration.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | Yes | string | The description of the field configuration. |
| `id` | Yes | integer | The ID of the field configuration. |
| `isDefault` | No | boolean | Whether the field configuration is the default. |
| `name` | Yes | string | The name of the field configuration. |
