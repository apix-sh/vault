# FieldConfigurationItem


A field within a field configuration.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | No | string | The description of the field within the field configuration. |
| `id` | Yes | string | The ID of the field within the field configuration. |
| `isHidden` | No | boolean | Whether the field is hidden in the field configuration. |
| `isRequired` | No | boolean | Whether the field is required in the field configuration. |
| `renderer` | No | string | The renderer type for the field within the field configuration. |
