# FieldUpdateOperation


Details of an operation to perform on a field.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `add` | No | any | The value to add to the field. |
| `copy` | No | any | The field value to copy from another issue. |
| `edit` | No | any | The value to edit in the field. |
| `remove` | No | any | The value to removed from the field. |
| `set` | No | any | The value to set in the field. |
