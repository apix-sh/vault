# FilterSubscription


Details of a user or group subscribing to a filter.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `group` | No | allOf(1) | The group subscribing to filter. |
| `id` | No | integer | The ID of the filter subscription. |
| `user` | No | allOf(1) | The user subscribing to filter. |
