# GroupLabel


A group label.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `text` | No | string | The group label name. |
| `title` | No | string | The title of the group label. |
| `type` | No | string | The type of the group label. Allowed values: ADMIN, SINGLE, MULTIPLE |
