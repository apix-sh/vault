# HealthCheckResult


Jira instance health check results. Deprecated and no longer returned.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | No | string | The description of the Jira health check item. |
| `name` | No | string | The name of the Jira health check item. |
| `passed` | No | boolean | Whether the Jira health check item passed or failed. |
