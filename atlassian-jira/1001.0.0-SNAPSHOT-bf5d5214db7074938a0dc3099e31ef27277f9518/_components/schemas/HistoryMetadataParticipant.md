# HistoryMetadataParticipant


Details of user or system associated with a issue history metadata item.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `avatarUrl` | No | string | The URL to an avatar for the user or system associated with a history record. |
| `displayName` | No | string | The display name of the user or system associated with a history record. |
| `displayNameKey` | No | string | The key of the display name of the user or system associated with a history record. |
| `id` | No | string | The ID of the user or system associated with a history record. |
| `type` | No | string | The type of the user or system associated with a history record. |
| `url` | No | string | The URL of the user or system associated with a history record. |
