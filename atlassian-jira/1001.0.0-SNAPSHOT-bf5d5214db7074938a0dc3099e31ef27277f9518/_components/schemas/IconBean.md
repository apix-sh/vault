# IconBean


An icon.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `link` | No | string | The URL of the tooltip, used only for a status icon. |
| `title` | No | string | The title of the icon, for use as a tooltip on the icon. |
| `url16x16` | No | string | The URL of a 16x16 pixel icon. |
