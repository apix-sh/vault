# IssueError


Describes the error that occurred when retrieving data for a particular issue.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `errorMessage` | No | string | The error that occurred when fetching this issue. |
| `id` | No | string | The ID of the issue. |
