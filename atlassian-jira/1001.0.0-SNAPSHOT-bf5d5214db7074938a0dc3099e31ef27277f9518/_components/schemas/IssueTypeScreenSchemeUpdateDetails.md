# IssueTypeScreenSchemeUpdateDetails


Details of an issue type screen scheme.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | No | string | The description of the issue type screen scheme. The maximum length is 255 characters. |
| `name` | No | string | The name of the issue type screen scheme. The name must be unique. The maximum length is 255 characters. |
