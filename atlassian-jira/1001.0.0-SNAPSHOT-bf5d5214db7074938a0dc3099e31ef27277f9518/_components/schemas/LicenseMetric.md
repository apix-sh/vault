# LicenseMetric


A metric that provides insight into the active licence details

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `key` | No | string | The key of a specific license metric. |
| `value` | No | string | The calculated value of a licence metric linked to the key. An example licence metric is the approximate number of user accounts. |
