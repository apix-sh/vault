# LicensedApplication


Details about a licensed Jira application.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `id` | Yes | string | The ID of the application. |
| `plan` | Yes | string | The licensing plan. Allowed values: UNLICENSED, FREE, PAID |
