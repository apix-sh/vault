# ProjectCategory


A project category.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | No | string | The description of the project category. |
| `id` | No | string | The ID of the project category. |
| `name` | No | string | The name of the project category. Required on create, optional on update. |
| `self` | No | string | The URL of the project category. |
