## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `id` | Yes | integer | The ID of the created project. |
| `key` | Yes | string | The key of the created project. |
| `self` | Yes | string | The URL of the created project. |
