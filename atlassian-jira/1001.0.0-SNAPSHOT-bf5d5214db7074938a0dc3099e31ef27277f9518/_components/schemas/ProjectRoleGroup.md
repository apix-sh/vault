# ProjectRoleGroup


Details of the group associated with the role.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `displayName` | No | string | The display name of the group. |
| `groupId` | No | string | The ID of the group. |
| `name` | No | string | The name of the group. As a group's name can change, use of `groupId` is recommended to identify the group. |
