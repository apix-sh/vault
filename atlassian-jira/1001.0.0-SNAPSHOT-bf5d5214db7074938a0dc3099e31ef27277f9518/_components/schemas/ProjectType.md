# ProjectType


Details about a project type.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `color` | No | string | The color of the project type. |
| `descriptionI18nKey` | No | string | The key of the project type's description. |
| `formattedKey` | No | string | The formatted key of the project type. |
| `icon` | No | string | The icon of the project type. |
| `key` | No | string | The key of the project type. |
