# QuickFilterPayload


The payload for defining quick filters

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | No | string | The description of the quick filter |
| `jqlQuery` | No | string | The jql query for the quick filter |
| `name` | No | string | The name of the quick filter |
