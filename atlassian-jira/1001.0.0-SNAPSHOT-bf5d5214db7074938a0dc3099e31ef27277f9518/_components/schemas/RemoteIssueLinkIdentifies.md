# RemoteIssueLinkIdentifies


Details of the identifiers for a created or updated remote issue link.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `id` | No | integer | The ID of the remote issue link, such as the ID of the item on the remote system. |
| `self` | No | string | The URL of the remote issue link. |
