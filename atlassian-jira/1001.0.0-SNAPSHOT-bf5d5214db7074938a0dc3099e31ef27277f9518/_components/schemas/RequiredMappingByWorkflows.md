# RequiredMappingByWorkflows


The list of required status mappings by workflow.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `sourceWorkflowId` | No | string | The ID of the source workflow. |
| `statusIds` | No | array<string> | The status IDs requiring mapping. |
| `targetWorkflowId` | No | string | The ID of the target workflow. |
