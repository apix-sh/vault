# Resolution


Details of an issue resolution.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | No | string | The description of the issue resolution. |
| `id` | No | string | The ID of the issue resolution. |
| `name` | No | string | The name of the issue resolution. |
| `self` | No | string | The URL of the issue resolution. |
