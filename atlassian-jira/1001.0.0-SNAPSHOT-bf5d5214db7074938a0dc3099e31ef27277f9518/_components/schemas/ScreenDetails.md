# ScreenDetails


Details of a screen.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | No | string | The description of the screen. The maximum length is 255 characters. |
| `name` | Yes | string | The name of the screen. The name must be unique. The maximum length is 255 characters. |
