# ScreenTypes


The IDs of the screens for the screen types of the screen scheme.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `create` | No | integer | The ID of the create screen. |
| `default` | Yes | integer | The ID of the default screen. Required when creating a screen scheme. |
| `edit` | No | integer | The ID of the edit screen. |
| `view` | No | integer | The ID of the view screen. |
