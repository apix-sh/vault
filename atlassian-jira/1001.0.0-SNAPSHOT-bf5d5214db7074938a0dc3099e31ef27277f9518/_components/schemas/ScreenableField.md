# ScreenableField


A screen tab field.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `id` | No | string | The ID of the screen tab field. |
| `name` | No | string | The name of the screen tab field. Required on create and update. The maximum length is 255 characters. |
