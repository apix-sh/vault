# SearchAutoCompleteFilter


Details of how to filter and list search auto complete information.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `includeCollapsedFields` | No | boolean | Include collapsed fields for fields that have non-unique names. |
| `projectIds` | No | array<integer> | List of project IDs used to filter the visible field details returned. |
