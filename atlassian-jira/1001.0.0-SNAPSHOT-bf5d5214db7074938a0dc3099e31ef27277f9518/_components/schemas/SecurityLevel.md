# SecurityLevel


Details of an issue level security item.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `description` | No | string | The description of the issue level security item. |
| `id` | No | string | The ID of the issue level security item. |
| `isDefault` | No | boolean | Whether the issue level security item is the default. |
| `issueSecuritySchemeId` | No | string | The ID of the issue level security scheme. |
| `name` | No | string | The name of the issue level security item. |
| `self` | No | string | The URL of the issue level security item. |
