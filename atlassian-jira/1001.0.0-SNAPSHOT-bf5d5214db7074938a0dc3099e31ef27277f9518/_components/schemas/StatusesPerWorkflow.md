# StatusesPerWorkflow


The statuses associated with each workflow.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `initialStatusId` | No | string | The ID of the initial status for the workflow. |
| `statuses` | No | array<string> | The status IDs associated with the workflow. |
| `workflowId` | No | string | The ID of the workflow. |
