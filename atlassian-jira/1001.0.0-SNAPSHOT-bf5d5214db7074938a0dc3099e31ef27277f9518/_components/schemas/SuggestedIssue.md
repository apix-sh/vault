# SuggestedIssue


An issue suggested for use in the issue picker auto-completion.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `id` | No | integer | The ID of the issue. |
| `img` | No | string | The URL of the issue type's avatar. |
| `key` | No | string | The key of the issue. |
| `keyHtml` | No | string | The key of the issue in HTML format. |
| `summary` | No | string | The phrase containing the query string in HTML format, with the string highlighted with HTML bold tags. |
| `summaryText` | No | string | The phrase containing the query string, as plain text. |
