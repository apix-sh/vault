# TimeTrackingDetails


Time tracking details.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `originalEstimate` | No | string | The original estimate of time needed for this issue in readable format. |
| `originalEstimateSeconds` | No | integer | The original estimate of time needed for this issue in seconds. |
| `remainingEstimate` | No | string | The remaining estimate of time needed for this issue in readable format. |
| `remainingEstimateSeconds` | No | integer | The remaining estimate of time needed for this issue in seconds. |
| `timeSpent` | No | string | Time worked on this issue in readable format. |
| `timeSpentSeconds` | No | integer | Time worked on this issue in seconds. |
