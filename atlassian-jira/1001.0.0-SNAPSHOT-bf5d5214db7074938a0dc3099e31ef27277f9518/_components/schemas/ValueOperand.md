# ValueOperand


An operand that is a user-provided value.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `encodedValue` | No | string | Encoded value, which can be used directly in a JQL query. |
| `value` | Yes | string | The operand value. |
