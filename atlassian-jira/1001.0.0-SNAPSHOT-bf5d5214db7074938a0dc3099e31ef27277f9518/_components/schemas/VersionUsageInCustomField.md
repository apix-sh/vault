# VersionUsageInCustomField


List of custom fields using the version.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `customFieldId` | No | integer | The ID of the custom field. |
| `fieldName` | No | string | The name of the custom field. |
| `issueCountWithVersionInCustomField` | No | integer | Count of the issues where the custom field contains the version. |
