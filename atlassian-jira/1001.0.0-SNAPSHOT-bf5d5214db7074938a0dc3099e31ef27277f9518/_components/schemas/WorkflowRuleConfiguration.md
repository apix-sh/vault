# WorkflowRuleConfiguration


The configuration of the rule.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `id` | No | string | The ID of the rule. |
| `parameters` | No | object | The parameters related to the rule. |
| `ruleKey` | Yes | string | The rule key of the rule. |
