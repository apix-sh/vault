# WorkflowTransitionProperty


Details about the server Jira is running on.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `id` | No | string | The ID of the transition property. |
| `key` | No | string | The key of the transition property. Also known as the name of the transition property. |
| `value` | Yes | string | The value of the transition property. |
