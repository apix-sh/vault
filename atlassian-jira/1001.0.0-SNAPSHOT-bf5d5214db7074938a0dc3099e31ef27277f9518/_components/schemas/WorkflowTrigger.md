# WorkflowTrigger


The trigger configuration associated with a workflow.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `id` | No | string | The ID of the trigger. |
| `parameters` | Yes | object | The parameters of the trigger. |
| `ruleKey` | Yes | string | The rule key of the trigger. |
