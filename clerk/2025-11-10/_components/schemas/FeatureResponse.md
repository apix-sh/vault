# FeatureResponse

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `avatar_url` | Yes | string | The URL of the feature's avatar image. |
| `description` | Yes | string | The description of the feature. |
| `id` | Yes | string | Unique identifier for the feature. |
| `name` | Yes | string | The name of the feature. |
| `object` | Yes | string | String representing the object's type. Objects of the same type share the same value. Allowed values: feature |
| `slug` | Yes | string | The URL-friendly slug for the feature. |
