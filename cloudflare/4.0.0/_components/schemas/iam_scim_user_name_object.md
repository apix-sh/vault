# iam_scim_user_name_object


The components of the user's real name.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `familyName` | No | string | The family name (last name) of the user. |
| `formatted` | No | string | The full name, including all middle names, titles, and suffixes as appropriate, formatted for display. |
| `givenName` | No | string | The given name (first name) of the user. |
