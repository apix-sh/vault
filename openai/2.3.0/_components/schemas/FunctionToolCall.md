# FunctionToolCall


A tool call to run a function. See the 
[function calling guide](/docs/guides/function-calling) for more information.


## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `arguments` | Yes | string | A JSON string of the arguments to pass to the function.<br/> |
| `call_id` | Yes | string | The unique ID of the function tool call generated by the model.<br/> |
| `id` | No | string | The unique ID of the function tool call.<br/> |
| `name` | Yes | string | The name of the function to run.<br/> |
| `status` | No | string | The status of the item. One of `in_progress`, `completed`, or<br/>`incomplete`. Populated when items are returned via API.<br/> Allowed values: in_progress, completed, incomplete |
| `type` | Yes | string | The type of the function tool call. Always `function_call`.<br/> Allowed values: function_call |
