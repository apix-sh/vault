# LogProbProperties


A log probability object.


## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `bytes` | Yes | array<integer> | The bytes that were used to generate the log probability.<br/> |
| `logprob` | Yes | number | The log probability of the token.<br/> |
