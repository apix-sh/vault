# Scroll


A scroll action.


## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `scroll_x` | Yes | integer | The horizontal scroll distance.<br/> |
| `scroll_y` | Yes | integer | The vertical scroll distance.<br/> |
| `type` | Yes | string | Specifies the event type. For a scroll action, this property is <br/>always set to `scroll`.<br/> Allowed values: scroll |
| `x` | Yes | integer | The x-coordinate where the scroll occurred.<br/> |
| `y` | Yes | integer | The y-coordinate where the scroll occurred.<br/> |
