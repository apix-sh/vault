# WebSearchLocation


Approximate location parameters for the search.

## Properties

| Property | Required | Type | Description |
| :------- | :------: | :--- | :---------- |
| `city` | No | string | Free text input for the city of the user, e.g. `San Francisco`.<br/> |
| `country` | No | string | The two-letter <br/>[ISO country code](https://en.wikipedia.org/wiki/ISO_3166-1) of the user,<br/>e.g. `US`.<br/> |
| `region` | No | string | Free text input for the region of the user, e.g. `California`.<br/> |
| `timezone` | No | string | The [IANA timezone](https://timeapi.io/documentation/iana-timezones) <br/>of the user, e.g. `America/Los_Angeles`.<br/> |
