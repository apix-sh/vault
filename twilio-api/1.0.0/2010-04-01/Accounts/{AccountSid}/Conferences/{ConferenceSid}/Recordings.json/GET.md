# Retrieve a list of recordings belonging to the call used to make the request

Retrieve a list of recordings belonging to the call used to make the request

## Path Parameters

| Name | Required | Type | Description |
| :--- | :------: | :--- | :---------- |
| `AccountSid` | Yes | string | The SID of the [Account](https://www.twilio.com/docs/iam/api/account) that created the Conference Recording resources to read. |
| `ConferenceSid` | Yes | string | The Conference SID that identifies the conference associated with the recording to read. |
